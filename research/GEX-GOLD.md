# Gamma Exposure по золоту: как получить Call Wall и Put Wall

**[МОЁ] Этого слоя нет в методологии A+.** Проверено поиском по всему архиву:
`gamma` 0 совпадений, `GEX` 0, `dealer` 0, `put/call wall` 0. Это твоё дополнение
к их методу, а не часть методологии. Подробности в `A-PLUS-TRADES-methodology.md`, раздел 11.

---

## 1. Источник данных

У спотового XAUUSD опционов не существует. Гамма считается по **GLD**, это SPDR Gold Shares,
единственный крупный золотой ETF с ликвидными опционами.

Публичный источник цепочки, без регистрации и без оплаты:

```
https://cdn.cboe.com/api/global/delayed_quotes/options/GLD.json
```

**Проверено:** суммы открытого интереса из этого файла совпали с тем, что показывает
InsiderFinance, до единицы (call OI 4 474 188, put OI 2 084 116). То есть сервис берёт
те же данные, и платить за них не обязательно.

## 2. Определение стен

Реверс-инжинировано по InsiderFinance, воспроизводит его цифры точно.

```
GEX(контракт) = gamma × OI × 100 × spot² × 0.01,   знак + для колов, − для путов
Net(страйк)   = сумма всех колов и путов на этом страйке
Call Wall     = страйк с максимальным Net ВЫШЕ спота
Put  Wall     = страйк с минимальным Net НИЖЕ спота
```

Важная деталь: стены считаются по **чистой** гамме страйка, а не отдельно по колам и путам.
Если брать только колы, максимум всегда садится на ATM-страйк, потому что гамма там пиковая,
и стена теряет смысл.

## 3. Пересчёт в XAUUSD

GLD котируется в долларах за акцию, золото в долларах за унцию. Нужен коэффициент:

```
коэффициент = цена XAUUSD / цена GLD
уровень_золото = уровень_GLD × коэффициент
```

**Коэффициент не константа.** У GLD комиссия 0.40% годовых, акция медленно отстаёт от спота,
множитель со временем растёт. Пересчитывай каждый раз, не запоминай.

## 4. Скрипт

`tools/gld_gex_walls.py` делает всё сам: тянет цепочку, считает стены по горизонтам,
переводит в золото.

```
python3 tools/gld_gex_walls.py 4373.9
```

|---|---|---|---|---|
| Все экспирации | $450 | **4 910** | $390 | **4 255** |
| Ближайшие (18–24 сен) | $415 | **4 528** | $390 | **4 255** |
| Месячная 16 окт | $450 | 4 911 | $400 | **4 366** |

Net GEX положительный, +0.96B. Цена выше Zero Gamma.
Стандартная трактовка: режим **положительной гаммы**, дилеры гасят волатильность,
продают рост и выкупают падение. Это режим ротации, а не тренда.

## 7. Ограничения, которые не снимаются

**Шаг страйков.** У GLD страйки идут через $1–5, что в золоте составляет $11–55.
Гамма-уровни по золоту физически грубые и не дают точности, которую даёт SPY для индекса.

**GLD это не спот.** Хедж дилеров идёт в акции GLD. До лондонского внебиржевого спота
и до фьючерсов COMEX, где происходит основное ценообразование, эффект доходит разбавленным.
В SPX опционный рынок огромен относительно базового актива, в золоте нет.

**Стены далеко.** На замере выше ближайшая стена сверху отстоит на 3.5%, снизу на 2.7%.
Для дневной торговли это не рабочие уровни. Смена фильтра экспираций положение почти не меняет,
потому что открытый интерес концентрируется на круглых страйках 390, 400, 415, 450.

**Вывод [МОЁ]:** пользуйся этим как слабым подтверждающим слоем и как источником
далёких ориентиров, а не как источником точек входа. Совпадение стены с уровнем
из профиля или VWAP усиливает уровень. Сама по себе стена по GLD входом не является.

## 8. Альтернатива для чистых данных

Опционы на фьючерс золота COMEX, тикер **OG** на базовый актив GC. Это настоящий золотой
опционный рынок без прокси через ETF.

Два пути к ним:

**Вручную.** CME публикует открытый интерес по страйкам бесплатно. Готового дашборда нет,
нужна своя обработка файлов.

**Через ATAS.** У платформы есть штатные опционные модули: `Options GEX Profile`
(гамма по страйкам, Zero Gamma, стены, Max Pain, накопительная линия, Expected Move),
`Options Key Levels`, `Options OI Profile`, `Options Board`, `Options Strategy Analyzer`.
Считает по опционам на фьючерс, то есть даёт гамму по золоту напрямую, без пересчёта из GLD.

Требования: тариф **ULTRA** (в PRO опционного анализа нет), подключение через
**Interactive Brokers или Rithmic**, и отдельные разрешения на опционные данные биржи.
Модули в статусе беты.

**[МОЁ]** Дорого и избыточно для старта. Скрипт по GLD даёт сопоставимые уровни бесплатно,
просто грубее из-за шага страйков. Переходить на ATAS имеет смысл, только если гамма станет
постоянной частью процесса.
