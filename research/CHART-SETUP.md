## Лэйаут 1 — Weekly (4H)

Для недельного разбора. **[A+]** Они делают недельный взгляд именно на 4H (#7036, #7238, #7470).

| Что | Настройка |
|---|---|
| Таймфрейм | 4H |
| Fixed Range VP | на текущий месяц → даёт M-VAH, M-POC, M-VAL |
| Fixed Range VP | на текущий год → годовой профиль, «Left VP» в их терминах (#7179) |
| VWAP | Anchor Period = **Month**, полосы 1/2/3 |
| DXY | отдельной панелью |

## Лэйаут 2 — Daily (1H и 30m)

Для дневного разбора. **[A+]** Их дневные посты идут на 30m и 1H (#7306, #7593).

| Что | Настройка |
|---|---|
| Таймфрейм | 1H (основной) и 30m |
| Session Volume Profile | см. настройки ниже → дневные VA/POC по сессиям |
| Fixed Range VP | на текущую неделю → W-VAH, W-POC, W-VAL |
| VWAP | Anchor Period = **Week**, полосы 1/2/3 |
| CVD | отдельной панелью (фаза 5, не раньше) |

## Session Volume Profile (SVP) — точные настройки

| Параметр | Значение | Почему |
|---|---|---|
| Sessions | **All** | Золото торгуется круглосуточно. RTH-сессия отрезала бы азиатскую и лондонскую торговлю |
| Volume | **Total** | Режим Up/Down делит объём по направлению закрытия свечи, а НЕ по агрессору. Это не дельта. Для чтения формы профиля Total чище |
| Value Area Volume | **70** | Стандарт AMT. Не менять |
| Rows Layout | Number Of Rows | Либо Ticks Per Row, см. ниже |
| Row Size | **60** (не 24) | 24 строки на дневной диапазон золота в 80-120 долларов дают 3-5 долларов на строку. Слишком грубо, чтобы различить LVN |
| **Extend POC Right** | **включить** | Критично |
| **Extend VAH Right** | **включить** | Критично |
| **Extend VAL Right** | **включить** | Критично |

### Почему Extend Right критичен

**[A+]** Вся дневная логика построена на сравнении с предыдущей сессией:
«If the value area is developed again below the previous session's value area, it means sellers
are still willing to sell at lower levels» (#7220, #7224).
И прямые ссылки на «previous session's VAH / POC / VAL» (#7475, #7484, #7542).

Без продления вправо уровни вчерашней сессии обрываются на её границе, и ты физически
не видишь, тестирует ли сегодняшняя цена вчерашний VAH. Это превращает SVP из рабочего
инструмента в картинку.

### Number Of Rows против Ticks Per Row

**[МОЁ]** `Number Of Rows` даёт фиксированное количество строк независимо от диапазона дня.
Значит в узкий день строка мелкая, в широкий грубая, и HVN/LVN между днями несопоставимы.
`Ticks Per Row` даёт постоянный ценовой шаг строки. Методологически он правильнее,
но требует подбора под инструмент. Начни с Number Of Rows = 60, перейди на Ticks Per Row,
когда будешь уверенно читать профиль.

## VWAP — точные настройки

**[A+]** Присутствует в каждом разборе. Недельный и месячный, обязательно с отклонениями
(#7238, #7290, #7333, #7391, #7582).

Ставится **два отдельных экземпляра** индикатора:

### Экземпляр 1 — недельный (W-VWAP)
```
Inputs → Anchor Period        = Week
Inputs → Source               = hlc3 (по умолчанию)
Bands Settings → Calculate Bands Based On = Standard Deviation
Bands Settings → Band #1      = включить, множитель 1
Bands Settings → Band #2      = включить, множитель 2
Bands Settings → Band #3      = включить, множитель 3
```

### Экземпляр 2 — месячный (M-VWAP)
То же самое, но `Anchor Period = Month`. Полосы можно оставить только 1 и 2,
иначе график перегружается.

### Почему VWAP выглядит «узким»

Три причины, по убыванию частоты:

1. **Anchor Period = Session (значение по умолчанию).** VWAP сбрасывается каждый день.
   В понедельник утром или в начале любой сессии полос почти нет, они расходятся по мере
   накопления объёма. На часовике это выглядит как короткие обрывки. **Лечится сменой
   якоря на Week или Month.**
2. **Полосы 2 и 3 выключены.** По умолчанию включена только первая. Одна полоса ±1σ
   действительно идёт вплотную к цене.
3. **Это нормальное поведение сразу после якоря.** Полосы всегда узкие в начале периода
   и расширяются к концу. Именно поэтому A+ берут недельный и месячный якорь, а не сессионный.

### Anchored VWAP как отдельный инструмент

**[МОЁ]** В TradingView есть отдельный инструмент рисования `Anchored VWAP`: ты сам ставишь
точку старта. Полезно якорить на всплеск от новости, на экстремум свинга, на FOMC.
В материалах A+ событийное якорение прямо не описано, так что это моё дополнение, не их правило.

## Три ловушки

1. **VRVP (Visible Range) не годится для планирования уровней.** Он пересчитывается при каждом
   зуме и скролле. Уровень, который двигается от щипка пальцами, нельзя разметить до сессии.
   **[A+]** работают с фиксированными периодами: недельный, месячный, предыдущая сессия
   (#7450, #7456, #7484). VRVP оставь для быстрого обзора, не как источник уровней.

2. **Режим Up/Down в профиле — не дельта.** Он делит объём по направлению закрытия свечи,
   а не по тому, кто был агрессором. Подтверждением в смысле A+ он не является, для этого нужен CVD.

3. **[МОЁ] Спотовое золото не имеет централизованного объёма.** XAUUSD на OANDA это тиковый
   объём одного брокера. Форма профиля обычно похожа на настоящую, но CVD на таких данных
   производный. Для чистых данных строй профиль по фьючерсу GC на COMEX и переноси уровни
   на XAUUSD. Подробности в `LEARNING-PLAN.md`, фаза 0.

## Проверка, что лэйаут собран правильно

За 10 минут с нуля ты должен получить график, на котором одновременно видно:
M-VAH / M-POC / M-VAL, W-VAH / W-POC / W-VAL, VA и POC предыдущей сессии, продлённые вправо,
W-VWAP с тремя полосами, и DXY.

Если чего-то из этого нет, дневной разбор по методологии A+ собрать не получится.
